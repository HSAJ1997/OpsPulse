# OpsPulse

OpsPulse is a service dependency monitoring and incident intelligence platform.

It monitors applications and APIs, records their health and performance,
tracks dependencies between services, and helps identify the likely source
and blast radius of incidents. IE if 7 applications break it tries to find 
out if all 9 broke at the same time or if 1 was responsible for 4 and another
was resposible for 3 more.
